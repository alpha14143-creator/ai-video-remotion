# 台股 當沖 / 短線 交易助手（手機版）

手機打開網址就能用，也可以「加入主畫面」當 App 使用。

## 功能（下方 4 個分頁）
1. **🔥 今日 5 檔**：每個交易日收盤後自動選出當沖 2 檔和短線 3 檔，附上進場、停損、停利 1、停利 2、建議股數，以及扣掉手續費和稅之後的淨賺 / 淨賠
2. **🎯 查價格**：輸入任何股票代號，算出當沖 4 種情境和短線 4 種情境的進出場價格
3. **📒 紀錄**：記錄每筆交易，一鍵「平倉」，自動算損益、勝率、最大回撤和每月損益，並標示出場價比停損還差的交易
4. **⚙️ 設定**：本金、單筆風險 %、券商手續費折扣、備份和匯入

## 讓手機每天自動收到「今日 5 檔」（只要設定一次）
1. 把這個分支合併到 `main`
2. GitHub 專案 → **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**
3. 到 **Actions → 台股每日選股 → Run workflow** 手動跑第一次
4. 完成後的網址：`https://<帳號>.github.io/<專案名稱>/`，用手機打開後加入主畫面

之後每個交易日台北時間 15:37 左右會自動更新（GitHub 排程可能延遲 5～30 分鐘）。
注意：專案超過 60 天沒有任何更新時，GitHub 會自動停用排程，要到 Actions 頁面重新啟用。

## 在電腦上使用
```
node stock-journal/scripts/daily-picks.js   # 產生今日 5 檔（約 2 分鐘）
cd stock-journal && node server.js          # 打開 http://localhost:3000
```
需要 Node.js 18 以上，不用安裝任何套件。

## 選股方式
- 股票池：上市櫃成交金額前 300 名，排除處置股
- 當沖：20 日平均成交金額 5 億以上、每日波動 2.5～8%、多頭或空頭趨勢明確。進場價用樞紐點（R1/S1），停損 0.3 個 ATR，停利 0.5 / 1 個 ATR
- 短線：多頭中拉回 10 日線、帶量突破 20 日高點（空頭時相反）。停損抓近 10 日高低點，限制在 1～3 個 ATR、最多 8%；停利是停損距離的 2 倍和 3 倍
- 資料來源：證交所、櫃買中心 OpenAPI，Yahoo Finance 日 K

## 檔案
| 檔案 | 用途 |
|---|---|
| `index.html` | 手機網頁 |
| `plan-core.js` | 進出場價格計算（網頁和選股程式共用） |
| `scripts/daily-picks.js` | 每日選股，產生 `data/picks.json`、`data/snapshot.json` |
| `server.js` | 電腦上使用的本機伺服器 |
| `../.github/workflows/stock-daily-picks.yml` | 每日自動選股並發佈到 GitHub Pages |

交易紀錄只存在手機瀏覽器裡（localStorage），請定期在「設定」按「備份 JSON」。
