# 台股 當沖 / 短線 交易助手

## 怎麼開啟

**方法 A：直接用瀏覽器打開 `index.html`**
- 可以查詢上市股票、計算價格、記錄交易
- 上櫃股票查不到，可以改用「手動輸入昨日價格」只算當沖

**方法 B：用本機伺服器開啟（上市、上櫃都能查）**
```
cd stock-journal
node server.js
```
然後打開 http://localhost:3000 。需要 Node.js 18 以上，不用安裝任何套件。

## 功能
1. **🎯 進出場價格**：輸入股票代號，計算
   - 當沖：明日 4 種情境（做多突破、做多回測支撐、做空跌破、做空反彈遇壓）的進場、停損、停利 1、停利 2
   - 短線：4 種情境（拉回買、突破買、反彈空、跌破空）的進場、停損、停利
   - 依本金和單筆風險 % 算出建議股數，以及扣掉手續費、稅之後的淨賺 / 淨賠
   - 「帶入紀錄」：一鍵把計畫寫進交易紀錄
2. **📒 交易紀錄**：記錄當沖和短線的進出場，自動算手續費、證交稅、淨損益、勝率、最大回撤和每月損益，並會標示出場價比停損還差的交易

資料只存在瀏覽器（localStorage），請定期按「備份 JSON」。

> ⚠️ 這是機械式的技術分析計算，不是投資建議，請自行判斷、自負盈虧。
