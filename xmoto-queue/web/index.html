使用須知

  1. 本設備為機車自動清洗機，僅供清洗機車使用。
  2. 啟動機器前，所有人員務必離開洗車倉；洗車過程中請勿進入或停留。
  3. 洗車倉及周邊地面濕滑，請小心慢行。
  4. 嚴禁在洗車倉內嬉戲、玩耍。因不當使用造成設備損壞，須照價賠償；未遵守使用須知所發生之意外，請自行負責。

溫馨小提醒

  • 洗車時請勿打開擋門（自助洗車請依機器指示再進入刷洗）
  • 有些車種可能車廂會稍微進水，請儘量清空車廂
