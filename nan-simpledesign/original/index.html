HOW WE WORK

從第一次聊聊，到清楚交付。

01 / LISTEN

了解你的生活

從你的日常習慣、家庭成員與收納需求聊起，了解對家的想像，讓空間規劃貼近真實的生活。

02 / PLAN

丈量與平面配置

實地丈量並確認空間條件，依照生活需求安排動線、家具與收納配置，一起找到舒適順手的格局。

03 / DESIGN

做設計

以確認的平面配置為基礎，討論風格、材質、色彩與燈光，透過圖面與 3D 示意逐步確認空間細節。

04 / BUDGET

預算分配

依整體預算與使用需求，整理各項工程及設備費用，討論優先順序與取捨，讓每一筆投入都有清楚方向。

05 / BUILD

施工與現場

依確認的設計與工程範圍安排施工時程，協調工種與現場細節，並確認施作品質，逐步將設計落實為生活空間。

BEFORE WE START

你可能也想問

預算還沒確定，也可以先聊聊嗎？＋

可以。先分享大致預算與最想改善的部分，我們一起釐清必要項目、可調整項目與執行順序，再確認適合的服務範圍。

只需要 3D 或施工圖，可以合作嗎？＋

可以接受獨立製圖委託，也可與設計團隊長期合作。請提供現場丈量尺寸、現有圖面與需求，方便確認工作量及報價。

外縣市能遠端合作嗎？＋

製圖服務可討論遠端合作；請提供完整案場資料。涉及現場丈量、設計或工程配合的項目，服務地區與方式另行確認。
